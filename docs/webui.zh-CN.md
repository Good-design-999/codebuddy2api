# WebUI 使用指南

[返回首页](../README.zh-CN.md) · [English](webui.md)

## 打开管理界面

先按 [部署指南](deployment.zh-CN.md) 启动网关，再访问 `http://127.0.0.1:8787/dashboard`，使用当前 API key 登录。源码运行需先构建前端，Docker 构建已包含界面；非本机访问请使用 HTTPS。

未设置 key 时管理功能锁定。更换 key 后需重新登录，尚未完成的 OAuth 授权也需重新发起。

## 常用操作

- **运行概览**：查看请求、用量和凭证健康状态。官方账号余额可能包含其他客户端的使用。
- **凭证管理**：选择国内或国际站扫码添加账号，或导入 `.info`、ZIP 文件。区分人工停用、凭证级认证熔断和模型级 429 冷却；停用保留文件，删除会移除文件，仍有模型绑定时需先解除。导出含明文凭证，请勿分享。
- **模型路由**：设置模型启停、对外 ID、地域/产品和指定账号；绑定不可用时不会回退到未选账号。客户端使用这里发布的 ID。
- **日志审计**：筛选请求、查看失败详情。清空明细会保留历史统计。
- **系统设置**：修改可编辑项；热更新项立即生效，标记为重启生效的设置需手动重启。锁定项在启动配置中修改，优先级见 [进阶参考](advanced.zh-CN.md)。

**全部清空日志与统计不可撤销**，需输入弹窗中的确认文字并复核当前 API key；不会删除凭证或网关配置。

## 数据与备份

数据默认保存在 `auth/`，Docker 内为 `/data/auth`；本地可通过 `CODEBUDDY_AUTH_DIR` 指定目录，Compose 宿主机目录由 `CODEBUDDY2API_AUTH_PATH` 控制。

| 文件 | 内容 |
|------|------|
| `*.info` | 官方凭证原文；不迁入 SQLite |
| `control.sqlite3` | 网关设置、模型规则和凭证元数据 |
| `logs.sqlite3` | 请求明细与独立聚合统计 |

审计默认保留 30 天明细，逻辑明细预算 256 MiB，**不是数据库或数据目录的磁盘硬上限**。明细清理和容量淘汰不删除聚合历史；SQLite 失败诊断预算独立配置，默认 8192 字节。旧文本日志保留，不回填为精确统计。

请将整个数据目录挂载到可写的本地存储，不要仅挂载单个数据库文件，也不要让多个网关实例共用目录。

备份前先停止网关，再复制整个目录，包含数据库、可能存在的 WAL/SHM 文件、凭证及目录/积分状态文件；不要只备份 `.info`。备份包含私有数据，请妥善保管。

客户端密钥和地址的填写方式见 [客户端配置](clients.zh-CN.md)。
